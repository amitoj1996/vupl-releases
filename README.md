# Vupl downloads

Official standalone Windows installers for [Vupl](https://vupl.stream), an independent native Plex movie and series player.

[Download from Microsoft Store](https://apps.microsoft.com/detail/9NS56D9HQN2W) for the Store-verified edition and automatic updates. [Standalone development releases](https://github.com/amitoj1996/vupl-releases/releases) are also available for x64 and ARM64 PCs running Windows 11 22H2 or later.

Development installers use a self-signed development certificate and are **not publicly trusted by Windows**. They install no trusted-root certificate and do not change Windows trust settings. Standalone updates are manual. Settings and downloads are retained during updates and uninstall. Store and standalone editions use separate app data.

This repository contains public installers and release notes only. Application source is maintained separately. Third-party playback notices are bundled with the app; [corresponding playback component source and build materials](https://github.com/amitoj1996/vupl-third-party-source/releases/tag/libmpv-2026-10-16) are available separately.
